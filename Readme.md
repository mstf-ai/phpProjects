# 🐘 PHP Practice Projects

Welcome to my personal playground for mastering **PHP development**! This repository is a collection of my hands-on exercises, mini-projects, and algorithmic problem-solving scripts built while sharpening my backend development skills.

## 🚀 Repository Roadmap

This repository is organized into progressive categories, moving from core fundamentals to advanced web application concepts.

### 📁 1. Core Language Basics (`/01-basics`)
*   **syntax-basics.php**: Variable scopes, data types, and loose vs. strict comparisons.
*   **control-structures.php**: Implementation of complex loops and match expressions.
*   **array-manipulation.php**: Multidimensional arrays, sorting functions, and data transformations.

### 🛠️ 2. Object-Oriented PHP (`/02-oop`)
*   **Inheritance & Interfaces**: Building reusable, modular classes.
*   **Polymorphism**: Utilizing abstract classes to handle dynamic execution patterns.
*   **Exception Handling**: Custom error tracking using `try-catch` structural blocks.

### 🌐 3. Web & Database Integration (`/03-web-apps`)
*   **Form Validation**: Secure handling of `$_POST` and `$_GET` requests with data filtering.
*   **Session Manager**: Simple user authentication simulations utilizing secure cookies.
*   **PDO Database Wrapper**: Safe, SQL-injection-resistant MySQL interactions using prepared statements.

## 🛠️ Local Environment Setup

Follow these quick steps to pull down this code and run the practice scripts on your local system.

### Prerequisites
*   **PHP**: Version 8.1 or higher recommended.
*   **Database**: MySQL or MariaDB (required for database exercises).
*   **Composer**: Optional (used for later package management exercises).

### Installation Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com
   cd YOUR_REPO_NAME
   ```

2. **Run the built-in PHP development server**
   ```bash
   php -S localhost:8000
   ```

3. **Access the scripts**
   Open your preferred web browser and navigate to `http://localhost:8000`.
